After publishing to the intended repository, use Settings → Social preview →
Edit → Upload an image to set the preview. Its README image does not set that
separate field. [Official GitHub documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

Do not publish the private catalog, browser profiles/cookies, model/VM files,
native recovery checkpoints or unsanitized host state. The earlier reviewed ZIP
is an allowlisted review artifact; the live working directory is not automatically
a publication manifest. Review the exact outgoing tree before a first push.

No blanket code license is assigned here. Individual fonts, icons, sounds and
upstream assets retain the notices linked in the README.
