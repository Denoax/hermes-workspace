# Inspection and access limits

The source register uses explicit inspection labels. VISUAL_STILL means a published image or rendered static state was seen. It does not mean the application, transitions or performance were fully tested. Interactions exercised in source demos are named; uninterrupted timing review remains unverified.

Direct browser visual inspection covered the exact Awsmd shot, Jordan Hughes's original sidebar, Brainwave's first navigation slide, Rauno's craft index/tab prototype, Emil's paired popovers, published Things imagery, Apple's Flighty activity image and the native-chat concept that was rejected as a whole-app direction.

Lusion Labs remained blank after one reload. The current Lusion homepage stayed at its loader. The Paper demo controls were visible but the shader canvas was blank. No cause is inferred from these states. A separately published 2023 Awwwards Labs image was inspected; it does not prove the current site's appearance or motion.

Pinterest showed a persistent sign-in overlay. The public title/partial image and original-creator tracing were usable. No account was accessed, no hidden page state was used to bypass the overlay, and unresolved pin identity is retained. Search leads are not promoted to full visual inspections.

The source clips and six Rare UI component pins from the earlier research are deliberately reused. Current text access was refreshed where available, but the package does not claim fresh continuous playback of every old clip. Their prior identities and the latest exact-reference requirements are included.

Several discovery hubs returned limited or no content. COVERAGE.json records each. A directory homepage being readable is not evidence that every listed design was inspected. Provider-selected testimonials, Github stars, social likes, jury awards and firsthand app testing are different evidence categories.

No browser screenshots are saved in this deliverable. No third-party runtime image assets, generated media or original creator recordings are redistributed. Public source-image links are retained for reference; licenses for the actual code candidates are separately pinned. Named authorship is a provenance signal, not proof that every embedded image has a known creation history.

This research did not modify Mani's PC, the active v4 Codex task, services, models, authentication or publishing state. Native results in the next pass must come from the actual current PC.
