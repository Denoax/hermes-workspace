by the previous releases. This handoff is preparation; the executor's final
artifact must reflect what was actually merged, installed, run and inspected.

Return one `MANI_HERMES_V5_COMPLETE_REVIEW.zip` with:

- Exact final source, lockfiles, asset/build identities, licenses and source-to-

- One canonical acceptance inventory with per-row PASS/PARTIAL/BLOCKED/UNVERIFIED,
  precise evidence pointers and current runtime scope. Derive its summary from
  those final rows; no stale “publication pending” summary beside a published PASS.
- Actual pin/model/chat/stream/cancel/retry/attachment/permissions evidence and
  measured normal-model restoration, plus current guest receipts or exact block.

  technical timing limits. Human, physical devices/listening and reboot remain

  and remaining work. Exclude raw private CLI logs, credentials, browser profiles,
  catalogs, user chats/files, model weights, VM disks and private backup bytes.
- Recovery instructions with exact verified fingerprints and private backup path.
  Rollback restores changed source/units only when current checks match; preserve

  the extracted final source. Distinguish host/fixture/native checks and retain
  environment failures/skips. No test removal or loosened gate to obtain a total.

within current repository authorization. If publication is performed, verify the
remote commit/tree against the final source and the installed build; otherwise
state it as pending. Include a source export recipe and machine-readable diff
manifest. Re-verify exact audio bytes and configuration pins. Close acceptance
backends/workers, verify normal Qwen healthy/idle at context 65,536, and send one
new final production-pin message after cleanup. Make the app usable, not merely
its temporary test instance. Preserve those new messages.

Final response should give the exact commit/publication status, existing pin/URL,
what works, material pending items, ZIP size/SHA-256 and verified rollback path.
Do not call the project completely finished while mandatory native/reference rows
remain blocked. Offer Mani the actual reviewable motion and listening material
without claiming approval when he could not review it.
